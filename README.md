# Форсайт-навигатор

Рабочая среда, в которой преподаватель вуза проходит форсайт-цикл: вход в цикл и шесть этапов (I Проблематизация → VI Интеграция). На каждом этапе — задания с полями ввода, из ответов автоматически собирается проектный продукт этапа. После шести этапов у преподавателя — дорожная карта собственного развития, пакет прикладных продуктов для курса и рефлексивное портфолио; завершение VI этапа запускает новый виток спирали.

Приложение воспроизводит содержательно-процессуальную модель диссертационного исследования А.С. Соколовой «Форсайт-технология профессионального развития преподавателей вузов с использованием цифровых ресурсов» (специальность 5.8.7). Самарский национальный исследовательский университет имени академика С.П. Королёва; научный руководитель — д.п.н., проф. Левченко В.В.

## Возможности

- **Маршрут**: `/start` (профиль, экспресс-диагностика установки, самооценка S) → `/stage/1…6`. На экране этапа: опора (свёрнута), задания (одно раскрыто), живой продукт этапа, рефлексивная пауза, переход к следующему этапу.
- **Правило открытия**: следующий этап открывается после обязательных заданий и рефлексивной паузы; «Открыть досрочно» доступно всегда — этап помечается «пройден не полностью».
- **«Использовать с ИИ»**: промпт подставляет уже введённые ответы; квадратные скобки остаются только там, где данных ещё нет. Нажатия журналируются (для мини-портфолио 6.4). Вызовов моделей по API нет.
- **Портфолио** (`/portfolio`): шесть продуктов, версии дорожной карты (v1, v2 и далее по виткам) со сравнением, список витков, экспорт `.md`, печать/PDF, резервная копия `.json`.
- **Библиотека** (`/library`): лекции, 15 промптов в исходном виде, шесть шаблонов как пустые формы, цифровые ресурсы.
- **О технологии** (`/about`): концепция, модель (кликабельная спираль), результаты апробации, система обеспечения — текст дословно из исходного навигатора.
- **Демо-режим**: заранее заполненный учебный виток для показа на защите (5–7 минут), только просмотр, «Сделать копию и редактировать», увеличенный шрифт для проектора.
- Светлая/тёмная тема, мобильная вёрстка, без бэкенда: данные — в `localStorage` этого браузера.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest: продукты p1–p6, правила этапов, промпты, версии карты, экспорт/импорт, сверка контента
npm run build      # статическая сборка в dist/
npm run check:terms
```

## Деплой

Сборка статическая, маршруты в hash-режиме (`/#/stage/3`), `base: './'` — работает с любого пути.

- **GitHub Pages, автоматически**: в настройках репозитория *Settings → Pages → Source* выберите **GitHub Actions**. Каждый push в `main` запускает `.github/workflows/ci.yml`: тесты → сборка → проверка формулировок → публикация.
- **GitHub Pages, одной командой** с локальной машины: `npm run deploy` (публикует `dist/` в ветку `gh-pages`; в *Settings → Pages* укажите ветку `gh-pages`).
- **Vercel**: `npx vercel --prod` (настройки — в `vercel.json`).
- **Amvera**: конфигурация — в `amvera.yml` (среда «Node.JS Browser»: Amvera выполняет `npm install && npm run build` и раздаёт `dist/` через nginx). Создайте в Amvera приложение, на вкладке «Репозиторий» подключите этот GitHub-репозиторий (событие push, ветка `main`) и добавьте выданный адрес как webhook в *Settings → Webhooks* репозитория (Content-type `application/json`, тот же секрет). После этого каждый push в `main` пересобирает приложение.

## Контент

Весь текстовый контент (этапы, зоны, требования, группы ресурсов, промпты, шаблоны, лекции, критерии уровней, вопросы диагностики, результаты апробации) переносится из `source/forsight-navigator.html` скриптом без изменения текста:

```bash
npm run content    # source/forsight-navigator.html → src/content/*.ts
```

Тест `tests/content.test.ts` сверяет `src/content` с исходником; CI проверяет, что повторная генерация не даёт расхождений. Формулировки заданий — `src/content/tasks.ts` (раздел 5 ТЗ). Учебный демо-виток — `src/demo/demoRun.ts`: пример условного преподавателя, не данные апробации.

## Структура

```
source/forsight-navigator.html   исходник контента
scripts/extract-content.mjs      перенос контента в src/content
scripts/check-terms.mjs          реестр ограничений ТЗ (grep)
src/content/                     контент (сгенерирован) + задания
src/lib/                         модель данных, правила этапов, сборка продуктов, промпты, сравнение карт, экспорт/импорт
src/store/store.ts               zustand + persist (localStorage)
src/tasks/stage1…6.tsx           формы заданий
src/pages/                       экраны
src/demo/demoRun.ts              демонстрационный пример
tests/                           vitest
```

## Данные

Всё хранится в `localStorage` под ключом `forsight-navigator`. Резервная копия — *Настройки → Экспорт JSON*; восстановление — *Импорт JSON* (включая версии дорожной карты, журнал промптов и шаблоны библиотеки).
